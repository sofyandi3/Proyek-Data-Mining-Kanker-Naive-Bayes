# Kanker Kematian Analisis Naive Bayes

## Deskripsi
Proyek ini bertujuan untuk menganalisis data kematian akibat kanker di Amerika Serikat dari tahun 1930 hingga 2011 menggunakan algoritma Naive Bayes. Dataset yang digunakan berisi informasi tentang tingkat kematian akibat berbagai jenis kanker pada pria dan wanita.

## Dataset
Dataset ini diambil dari American Cancer Society dan mencakup data kematian akibat kanker per tahun. Beberapa jenis kanker yang dianalisis termasuk:
- Kanker Lambung
- Kanker Kolon dan Rektum
- Kanker Hati
- Kanker Pankreas
- Kanker Paru-paru
- Kanker Prostat
- Kanker Leukemia
- Kanker Payudara
- Kanker Rahim
